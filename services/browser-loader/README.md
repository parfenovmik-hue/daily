# Локальное чтение карточек товаров

Экспериментальный отдельный Node.js + Playwright сервис. Не подключён к PWA,
Apps Script или записям пользователей. Не вызывает платные API. На Mac использует
установленный Google Chrome с отдельным временным контекстом, без личного профиля.

## Запуск из корня Daily

Нужны Node.js >=22.13 и Google Chrome на Mac:

```sh
npm --prefix services/browser-loader ci
npm run browser:start
npm run browser:read -- 'https://example.com/product'
npm run browser:stop
npm run browser:test
```

Обычный видимый Chrome (оказался успешнее headless на проверенной ссылке Маркета):

```sh
DAILY_READER_HEADED=1 npm run browser:start
```

В текущем локальном сетевом окружении публичные сайты разрешаются в proxy-IP
240.0.0.x. Только для этого окружения добавлять `DAILY_READER_PROXY_DNS=1` перед
командой запуска. Опция допускает такие DNS-ответы лишь для перечисленных в
server.mjs доменов магазинов/CDN; приватные IP остаются запрещены. По умолчанию
действует строгая проверка публичного DNS. Системные настройки сети не меняются.

## Интерфейс и приватность

Слушает только 127.0.0.1:8841; GET /health — состояние. POST /extract с JSON
`{"url":"https://…"}` требует локальный Bearer token. CLI читает его автоматически
из игнорируемого private/browser-loader-connection.json (права 0600).
POST /shutdown останавливает сервис. Другие Origin запрещены. Публичные HTTPS
URL проверяются на основном запросе и подресурсах; WebSocket и загрузки отключены.
Это базовая защита локального прототипа, не готовая изоляция публичного сервиса.

Читается одна страница за раз; новый параллельный запрос получает 429.
Браузер закрывается через 60 секунд простоя, Node остаётся запущен до stop.
Возвращаются title, image, price, currency и evidence. Скриншоты остаются только
в private/browser-loader: автоматически сохраняются последние 20 PNG.
Проверки CAPTCHA не проходятся, отсутствующие значения не выдумываются.
Цена может зависеть от региона, способа оплаты и аккаунта: результат требует
проверки, прежде чем применять его к карточке Daily.

## Проверка на Mac · 6 ноября 2026

Контроль Books to Scrape: название, фото и 51.77 GBP получены.
Headless: Lamoda и Яндекс Маркет ответили HTTP 403.
Видимый Chrome: Яндекс Маркет, карточка 4745854146, открылся; название,
фото и 3433 RUB получены. Скриншот подтверждает цену, но она условная — с Пэй.
Lamoda RTLAFM604901: пустая страница HTTP 200, поля не получены.
Повторяемая работа всех маркетплейсов не подтверждена. Данные в PWA не менялись.
Отчёт текущего прогона: private/browser-loader/probe-report.json (не Git).

Измеренный пик суммы RSS Node и его процессов Chrome: около 1.25 GiB в видимом
режиме, около 1.1 GiB в headless. Общая память процессов может учитываться дважды;
это ориентир Mac, не гарантия для Linux. node_modules занимает около 18 MiB,
Chrome на Mac уже установлен. Для VPS предварительный запас: 2 GiB свободной RAM
и 2–3 GiB диска на браузер, библиотеки, сервис и ограниченные артефакты.

## Будущий сервер

Не развёрнут. На Linux понадобятся Chromium и системные библиотеки Playwright,
ограничение CPU/RAM, изоляция процесса и исходящей сети, аутентификация,
HTTPS и связь с backend. Нужна отдельная проверка доступности магазинов с IP VPS.
Существующие Telegram-боты не затрагивались. Текущий localhost недоступен с iPhone
и не является автоматически подключённым источником данных раздела «Хочу».
