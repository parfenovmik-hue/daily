# Daily — идеи для следующих этапов

## Повторяющиеся задачи

Не включать в первую версию. После проверки первой версии предложить владельцу
вернуться к этой функции и обсудить механику повторений.

Примеры: оплата интернета каждый месяц, уход за аквариумом каждую неделю.
Договорённость зафиксирована 1 ноября 2026 года во время анкетирования.

## ИИ-помощник

Позже обсудить предложения по распределению задач и шагам цели на основе
предыдущего опыта пользователя. Предложения не должны менять план без выбора
пользователя. Это пожелание, не обязательство первой версии.

## Другие отложенные возможности

- Напоминания и push-уведомления: стандартные веб-API и серверная отправка,
  учёт поддержки/разрешений на каждой платформе по PLATFORMS.md.
- Дополнительная тема оформления.
- Папки и файлы внутри проекта вместо простой страницы информации.
- Отдельный дедлайн, если одной даты станет недостаточно.
- Несколько ссылок на один товар.

- Свайп-меню с несколькими действиями — удачный механизм, вернуть при появлении новых операций. Сейчас для задач: вправо перенос, влево выбор обозначения; удаление в редакторе.

- Отображение проекта символом / эмодзи / аббревиатурой / логотипом — идея на будущее. Сейчас в редакторе только название и цвет; старые значения symbol сохранены в данных, интерфейс их не использует.

## Желания: разбор через API

Сейчас быстрый ввод одним текстовым полем без ИИ. Владелец попросил напомнить
о подключении API при следующей доработке желаний. Обсудить сервис и ключ,
разбор ссылки / личного заголовка / пометок и получение названия, изображения
и цены товара, особенно OZON и Wildberries. Ключ хранить только на сервере.
Никакие платные запросы до отдельного решения не запускать.
