## Другие отложенные возможности

- Напоминания и push-уведомления: стандартные веб-API и серверная отправка,
  учёт поддержки/разрешений на каждой платформе по PLATFORMS.md.
- Дополнительная тема оформления.
- Папки и файлы внутри проекта вместо простой страницы информации.
- Отдельный дедлайн, если одной даты станет недостаточно.
- Несколько ссылок на один товар.

- Свайп-меню с несколькими действиями — удачный механизм, вернуть при появлении новых операций. Сейчас для задач: вправо перенос, влево выбор обозначения; удаление в редакторе.

- Отображение проекта символом / эмодзи / аббревиатурой / логотипом — идея на будущее. Сейчас в редакторе только название и цвет; старые значения symbol сохранены в данных, интерфейс их не использует.
